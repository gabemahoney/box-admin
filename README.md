# box-admin

The public entry point for Gabe's box setup. The real repo, `gabemahoney/box-admin-core`, is private.

Clone this repo (or `git pull` it if it is already here), start Claude Code in it, and ask it to follow
this repo. CLAUDE.md tells it how to clone the private repo with the personal GitHub token, including
where to find the token when it is not in the shell. Never print, echo or log any token.
