# box-admin

The public entry point for Gabe's box setup. The real repo, `gabemahoney/box-admin-core`, is private.

Clone this repo (or `git pull` it if it is already here), start Claude Code in it, and ask it to follow
this repo. CLAUDE.md tells it how to clone the private repo: with the personal GitHub token from its own
environment, else gh's existing login, else a one-time `gh auth login --web` that you run in a terminal.
Never print, echo or log any token, and never paste one into a chat.
